## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
SQLite for Mojo that returns the same rows as Python's `sqlite3`, byte for byte, and
runs 2.7× faster on inserts and 4× to 5.5× faster on scans. It loads the system
`libsqlite3.so.0` at run time, so it needs no linker flags.

```mojo
from sqlite import Database

def main() raises:
    var db = Database("jobs.db")
    var q = db.prepare("SELECT id, cmd FROM jobs WHERE prio >= ?")
    q.bind(1, 10)
    while q.step():
        print(q.int(0), q.text(1))
```
