# mojo-sqlite v0.1.0

**Released:** 2026-10-21 · **Commit:** `6798b4c` · **Previous:** first release

## What it does

SQLite for Mojo that returns the same rows as Python's `sqlite3`, byte for byte, and
runs 2.7× faster on inserts and 4× to 5.5× faster on scans. It loads the system
`libsqlite3.so.0` at run time, so it needs no linker flags.

```mojo
from sqlite import Database

def main() raises:
    var db = Database("jobs.db")
    var q = db.prepare("SELECT id, cmd FROM jobs WHERE prio >= ?")
    q.bind(1, 10)
    while q.step():
        print(q.int(0), q.text(1))
```

## Highlights

- `Database` and `Statement`: prepare once, bind, step, reset, transactions, typed reads.
- Every SQLite value type: integers, floats, text, BLOBs, NULL; parameters by position
  or by name (`:prio`, `@prio`, `$prio`).
- `text_view()` and `blob_view()` read in place from sqlite's buffer, with no copy.
- Errors carry sqlite's own message: `sqlite: UNIQUE constraint failed: u.k (rc 19)`.
- Docs in `docs/`, a skill file for coding agents in `skills/mojo-sqlite/SKILL.md`.
  Apache-2.0.

## Known limits

- Linux only: the library is loaded as `libsqlite3.so.0`.
- One connection per `Database`; do not share a `Database` or `Statement` across threads.
- No Mojo package registry yet: install from source, a precompiled `.mojoc`, or by vendoring.

## Upgrade / run

```
git clone https://github.com/amarbaro/mojo-sqlite && cd mojo-sqlite && uv sync
mojo run -I src examples/quickstart.mojo
```
